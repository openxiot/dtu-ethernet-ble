# 说明

这是一个DTU板子，作用是将485接口的数据和网络数据互相转发。

1. MCU型号：CH32V208GBU
2. 有网口，可以访问互联网。
3. 有485接口，PA2/PA3/PA4 接了SP485（485收发器）: PA3接RO, PA2接DI, PA4接RE/DE。
4. 烧写管脚：PA13 > SWIO, GND > GND, PA14 > SWCK, VDD > VDD(3V3)，我用WCH-LINK板子，如何接这个烧写管脚？

    CH32V208GBU 使用标准 2 线调试接口（SWD），直接对照 WCH-LINK 排针标注接线即可：

   | WCH-LINK 标记  | 板子管脚        |
   | -------------- | --------------- |
   | 3V3            | VDD（3V3）     |
   | GND            | GND             |
   | SWDIO          | PA13（SWIO）   |
   | SWCLK          | PA14（SWCK）   |
   | RST            | RST（复位，建议接）|

    要点：
    1. PA13 对应 SWDIO、PA14 对应 SWCLK，是芯片默认调试脚，无需额外配置；新版 WCH-LinkE 同样接这 4 根线。
    2. WCH-LINK 的 3V3 是电源输出脚，建议板子直接由其供电，并确保板子电源为 3V3，不要接 5V。
    3. 连接完成后，用 WCH 官方工具 MounRiverStudio 即可烧录与调试。

5. DTU 固件（本工程已实现）：上电经以太网以 wss 连接
   `ws.dtu.ap.openxiot.cn/v1/yinerda/yed-s710ym/{IMEI}`，模拟 yeds710ym 设备，
   上报心跳/csq/coordinates 并应答查询。

   - 需要修改的设备参数（IMEI、上报值、联网方式等）集中在 `User/dtu_config.h`。
   - 工程已把 WCH CH32V20xEVT 的 NetLib（`Net/NetLib/`）拷入，`.cproject` 已配置好：
     源文件（含 `User/*.c`、`Net/NetLib/eth_driver.c`）、`libwchnet.a` 链接、
     头文件搜索路径（`User/`、`Debug/`、`Net/`、`Net/NetLib/`）都已在工程文件里加上，
     直接用 MounRiverStudio 打开一键构建即可（不用手动加）。
     系统时钟已在 `User/system_ch32v20x.c` 设为 120MHz（以太网要求 60/120MHz）。
   - `DTU_TLS`（dtu_config.h）=1 走 wss：**需一个 TLS 引擎**（WCHNET 只提供 TCP），
     接口在 `User/wss_tls.c`，是目前唯一未随仓库提供、需接入的组件；
     =0 走明文 ws，可先用来自建/直连调试整条 DTU 链路。
   - 编译通过的便携协议层（sha1/base64、WebSocket 握手/分帧/掩码/ping-pong、查询应答）
     已在本机用脚本对本地 WebSocket 服务端做联测通过。
